# Sales Analysis Dashboard

## Project Description
This project is a Sales Analysis Dashboard built using Python and Streamlit.

## Features
- Sales Visualization
- Data Analysis
- Interactive Dashboard

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy

## Dataset
superstore.csv (configurable via DATA_FILE environment variable)

## Run

Install requirements

pip install -r requirements.txt

Run

streamlit run app.py
